# Story Forensics Skill

Use this skill when analyzing interview transcripts or raw client notes.

## 1. The Gap Search
Look for the distance between:
- **The Stated Problem:** What the client thinks is the issue.
- **The Structural Constraint:** The underlying system holding them back.
- **The Outcome:** The "Signal" of what they truly want.

## 2. Archetype Detection
Analyze the client's language to assign a high-value archetype:
- **The Systems Integrator** (e.g., Greg Brandon)
- **The Change Architect** (e.g., Christopher Liechty)
- **The Deep Value Specialist** (e.g., Susan Malandrino)

## 3. Linguistic Reframing
Convert "Commodity Language" into "Strategy Language":
- Instead of "I make videos" -> "I architect visual mission control systems."
- Instead of "I help people" -> "I engineer social infrastructure."
- Instead of "I am a manager" -> "I calibrate operational performance for scale."

## 4. Signal Extraction
Find the "Pull Quote" – a single phrase said in passing that contains the entire mission. 
*Example: "The vessel is valuable because of the space inside it."*
