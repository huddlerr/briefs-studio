# Narrative Architecture Skill

Use this skill when the user provides raw context, transcripts, or notes and wants to build a structured Signalform Brief.

## 1. The Core Structure
Every narrative must be broken down into these specific "Signalform" modules:
- **The Throughline:** A single, sharp sentence that reframes the client's identity.
- **The Problem Layer:** (Surface Level -> Deeper Level -> Structural Constraint).
- **The Path:** The specific "How" of the solution.
- **The Purpose:** The 50-year-old test (legacy) and the immediate "Why".
- **The Roadmap:** A tactical 18-month execution plan.

## 2. Voice & Tone
- **Technical but Poetic:** Use industry-specific terminology but frame it within a larger story.
- **Tactical Editorial:** It should feel like a high-end magazine met a military situation report.
- **Authority:** Do not use "maybe" or "perhaps." Use active, definitive language.

## 3. Formatting
- Use **Bold Lead-ins** for all bullet points.
- Use `mono` font for all data points or metadata.
- Use `serif` font for all narrative "pull quotes."

## 4. Prompting the Architecture
When generating content, ask yourself: *"Does this reframe the client as a high-value system, or just a service provider?"*
- **Old Narrative:** Service provider.
- **New Narrative:** Strategic infrastructure.
