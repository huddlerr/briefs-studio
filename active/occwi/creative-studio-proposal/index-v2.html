07 // OPERATIONAL PROTOCOLS & SECURITY

Minimal Surface Area, Maximum Security.

Systems Access

Lead (Mike Marrotte) maintains GFE access for secure file transfer. All specialist creatives work on commercial equipment using industry-standard tools (Adobe, Figma, VS Code), reducing the total number of individuals requiring government system access.

File Transfer Protocol

Deliverables are transferred via existing, approved channels including DOD Safe and encrypted physical drives. Small assets (HTML/CSS) are delivered directly to Deloitte technical points of contact for GFE integration.

Meeting Protocol

Creatives remain focused on production; client interaction occurs through focused team touchpoints and working sessions to create assets dynamically and rapidly.

Technical Integration

Small-footprint HTML/JS logic and video production assets delivered via approved channels. Direct GFE integration managed by Lead Architect (Mike Marrotte).
