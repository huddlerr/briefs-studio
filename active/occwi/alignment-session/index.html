01 // THE CHALLENGE

Strategic conversations are happening, but they lack durable reference points.

"How do we take two leaders with different organizational contexts and create a shared understanding that outlives leadership transitions?"

The Convergence Challenge

Problem // 01

Discussions happen repeatedly without creating artifacts.

Problem // 02

Complex organizational relationships remain undefined.

02 // METHODOLOGY

The session uses the Story Portrait methodology—a structured framework designed to surface tacit knowledge and convert complex conversation into actionable narrative artifacts.

Movement 01

Problem

What needs clarifying? What misalignments or gaps exist today?

Movement 02

Path

What are the key relationships, structures, and flows that define the system?

Movement 03

Purpose

What does success look like? What can this artifact enable tomorrow?

03 // SESSION STRUCTURE
00-05 MIN

Opening

Establish ground rules: this is thinking out loud, not polished answers.

05-30 MIN

Problem Extraction

Identifying when language causes confusion across organizations.

30-70 MIN

System Pathing

Mapping essential nodes: OCCWI, TFF, and IPPW equities.

70-90 MIN

Purpose Alignment

Success criteria: What decisions does this clarity unlock?

Inquiry Protocol
  • "When you say 'resilience system,' what are you each picturing?"

    Surface competing frameworks or undefined terms early.

  • "How do OCCWI equities and TFF equities relate to each other?"

    Define boundaries, interfaces, and resource flows.

  • "What decisions can't be made without clearer definitions?"

    Identify leverage points where clarity creates momentum.

04 // THE ARTIFACT
The Output

Narrative Map

A structured document (8-15 pages) that includes System Architecture, Visual Maps, and Narrative Framing written in shared language.

Visual

Nodes, relationships, and organizational boundaries.

Strategic

Decisions unblocked and briefing ready.

Durable

Language that survives leadership changes.

Field-Ready

Where IPPW operations fit in the frame.

05 // PRODUCTION METHODOLOGY
During Session
  • • Audio recording & transcription
  • • Live note-taking (Mike + support)
  • • Visual sketching of emerging ties
Synthesis (Days 1-5)
  • • Pattern & tension analysis
  • • Direct participant language integration
  • • High-fidelity map architecture
Review (Days 5-7)
  • • Draft delivered for review
  • • Feedback session (30-60 min)
  • • Final refined artifact delivery

Technical Approach: Synthesis is human-driven using structured templates. AI augmentation (if used) is restricted to de-identified structural elements only.

06 // PREPARATION

Critical questions for Elizabeth & Teresa before scheduling:

Stakeholders & Scope
  • • Who else needs to validate this definition once created?
  • • Are there specific aspects of "resilience system" that MUST be addressed?
  • • Any topics that are out of scope or too politically sensitive?
Logistics & Use Cases

  • • Implementation: What is the first place you'll use this artifact?
07 // TIMELINE & SUCCESS

Success Criteria

  • ✓ Shared vocabulary unblocks critical decisions.
  • ✓ Organizational relationships clarified in writing.
  • ✓ The definition "survives" external explanation.

Investment
